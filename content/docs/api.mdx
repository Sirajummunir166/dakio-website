`@dakio/sdk` wraps this API; you can call it directly from any language.

```bash
curl https://dakio-api-production.up.railway.app/api/sdk/v1/products?limit=2 \
  -H "Dakio-Key: dk_pub_test_…"
```

## Checkout body

```json
{
  "customer": { "name": "Rahim", "phone": "01712345678", "address": "House 4, Road 2", "district": "Dhaka", "city": "Mirpur", "email": null },
  "items": [{ "productId": "cm…", "variantId": null, "qty": 2 }],
  "couponCode": "EID10",
  "note": "Call after 5pm",
  "eventId": "pur_…"
}
```

`201` → `{ "data": { "orderNumber": "#ABC-1234", "orderId": "cm…", "total": 1060 } }`. `202` → `{ "data": { "status": "OTP_REQUIRED", "sessionToken": "…", "maskedPhone": "01*******78", "expiresAt": "…" } }`. Test keys add `"test": true`. Up to 50 lines, quantities 1–999.
